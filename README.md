# 🏥 MediCare Hub — ონლაინ სამედიცინო სერვისების პლატფორმა

**MediCare Hub** წარმოადგენს სამედიცინო სერვისებისა და ექიმთან ვიზიტების სამართავ ვებ-პლატფორმას[cite: 13, 14]. აპლიკაცია მომხმარებელს აძლევს საშუალებას მოიძიოს სასურველი კვალიფიკაციის ექიმი სპეციალობის მიხედვით, გაეცნოს განრიგს და ონლაინ დაჯავშნოს ვიზიტის სასურველი დროის სლოტი.

---

## 🛠️ ტექნოლოგიური სტეკი (Tech Stack)

- **Frontend Core:** React 18 (Hooks: useState, useEffect, useMemo, useCallback, Suspense, React.lazy)
- **Styling & UI:** Tailwind CSS (Mobile-First არქიტექტურა, 8px Grid სისტემა)
- **არქიტექტურა და მდგრადობა:** Custom Hooks (useDoctors), Error Boundary (Fallback UI), ლოკალური Mock მონაცემთა მართვა (Offline Fallback)[cite: 13]
- **Build Tool:** Vite

---

## 🚀 ლოკალურად გაშვების ინსტრუქცია (Getting Started)

პროექტის თქვენს ლოკალურ სამუშაო გარემოში გასაშვებად შეასრულეთ შემდეგი ნაბიჯები:

1. დააკლონირეთ რეპოზიტორია:
   git clone https://github.com/ElenLabartkava/medicare-hub.git

2. გადადით პროექტის საქაღალდეში:
   cd medicare-hub

3. დააინსტალირეთ საჭირო დამოკიდებულებები:
   npm install

4. გაუშვით დეველოპმენტ სერვერი:
   npm run dev

ლოკალური სერვერი გაეშვება მისამართზე: http://localhost:5173
