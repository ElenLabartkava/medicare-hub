# 🚀 MediCare Hub — ონლაინ სამედიცინო სერვისებისა და ვიზიტების მართვის პლატფორმა

**Live Demo:** [https://medicare-hub-theta.vercel.app/](https://medicare-hub-theta.vercel.app/) _(ან ეშვება ლოკალურად: http://localhost:5173)__(ან ეშვება ლოკალურად: http://localhost:5173)_  
**კატეგორია:** სამედიცინო ჰაბი / HealthTech პლატფორმა

---

## 📖 პროექტის შესახებ

**MediCare Hub** არის React 18-ზე დაფუძნებული თანამედროვე ვებ-აპლიკაცია, რომელიც ამარტივებს პაციენტებისთვის სამედიცინო სერვისების მიღებას. პლატფორმა მომხმარებელს აძლევს საშუალებას რეალურ დროში მოიძიოს სასურველი კვალიფიკაციის ექიმი სპეციალობის მიხედვით, გაეცნოს მის განრიგს, ფასებს და დაჯავშნოს ვიზიტის სასურველი დროის სლოტი ზედმეტი სატელეფონო ბიუროკრატიის გარეშე. აპლიკაცია ასევე მოიცავს სამუშაო სივრცეებს ექიმებისთვის (განრიგის კონტროლი) და ადმინისტრატორებისთვის (პერსონალის მართვა).

---

## ✨ ძირითადი ფუნქციონალი

- **მონაცემთა მართვა (CRUD & State):** რეალიზებულია ცენტრალიზებული Zustand Store-ით. ექიმის დამატება, წაშლა და ვიზიტის დაჯავშნა ხდება მყისიერად, ხოლო persist middleware-ის საშუალებით მონაცემები ავტომატურად ინახება ბრაუზერის localStorage-ში (medicare-hub-storage), რაც გამორიცხავს მონაცემების დაკარგვას გვერდის განახლებისას.
- **ძიება და ფილტრაცია:** ოპტიმიზებული ძიება ექიმის სახელისა და სპეციალობის მიხედვით; დინამიური ფილტრაცია კატეგორიების (კარდიოლოგია, პედიატრია, ნევროლოგია და ა.შ.) მიხედვით useMemo-ს ოპტიმიზაციით.
- **მოდალური ფანჯრები და ფორმები:** ინტერაქციული მოდალები (Modal.jsx) კალენდრითა და თავისუფალი დროის სლოტებით ვიზიტის დასაჯავშნად, ასევე ადმინისტრატორის მიერ ახალი ექიმის დასარეგისტრირებლად (DoctorForm.jsx).
- **მდგრადობა (Resilience & Defensive Programming):**
  - ErrorBoundary იცავს აპლიკაციას კრიტიკული შეცდომებისგან (თეთრი ეკრანის თავიდან აცილება და Retry მექანიზმი).
  - Double-Click ბლოკირება (bookingInProgressId), რაც გამორიცხავს ერთი და იმავე ჯავშნის დუბლირებას.
  - Offline Fallback რეჟიმი ქსელური შეფერხებების სიმულაციისა და ტესტირებისთვის.
- **Responsive დიზაინი:** სრულად ადაპტირებული ინტერფეისი Desktop (1440px), Tablet (768px) და Mobile (375px) ეკრანებისთვის ჰამბურგერ-მენიუთი და Touch Target-ის დაცვით (>44px).
